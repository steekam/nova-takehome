Step 3 · Future extension

Source ingestion with review

The current product does not create or publish sources in the UI. This proposed flow shows how a later ingestion feature could preserve provenance and version history.

Proposed import pipeline

Not implemented
1 · ImportKeep the original file and revision
2 · ExtractText, headings, tables, page refs
3 · ReviewLead confirms target links and excerpts
4 · ChunkPreserve meaning and provenance
5 · EmbedReuse cached vectors where valid
6 · PublishEnable retrieval after full indexing
For the current slice, catalogue data enters through seed/import. The library exposes its hierarchy, source revisions, references, and readiness for inspection.

Version and audit rules

Proposed
Keep source revisions immutable.

A new revision never changes citations already attached to lesson-plan versions.

Publish only complete indexes.

Retrieval sees approved chunks only after every chunk and vector is stored.

Record provenance at extraction.

Keep page, heading path, source code, and exact catalogue target links.

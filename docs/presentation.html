Schema growth

Adding curriculum coverage

New coverage adds rows to the same catalogue and source model.

Rows added

  • New grade or subject
    Level and offering, then edition-owned nodes and outcomes.
  • New edition
    New design version, nodes, and target wording; supersedes_id links its predecessor.
  • New evidence
    Resource revision, chunks, embeddings, and a target link with role and status.

What stays stable

  • Earlier plans retain the exact target revision they used.
  • Retrieval only uses published sources linked to the selected target.
  • Plan contracts stay the same as more curriculum paths are added.

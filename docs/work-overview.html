Failures are part of the design

Stable codes tell the caller what failed and what to fix.

RETRIEVAL_EVIDENCE_INSUFFICIENT

Required target or lesson evidence is missing. Stop before provider call.

LLM_INVALID_RESPONSE

Provider output cannot be repaired within the bounded attempt. Save no draft.

LESSON_PLAN_QA_FAILED

Return failed checks and field-level corrections; do not submit or publish.

PLAN_TRANSITION_INVALID

Action is illegal in the current state. Keep the record unchanged.

REVIEW_COMMENT_REQUIRED

Returning needs at least eight non-space characters; the UI shares that rule.

LLM_* / EMBEDDING_*

Classify provider/cache errors by stage and retryability; preserve a JSON failure report.

Scope and handoff

Intentionally bounded

  • CBC only; Cambridge coverage removed from the current task slice.
  • The demo catalogue has nine short source resources. Only Grade 8 Integrated Science 1.2(a) has official grounding; the other CBC paths are browse-only.
  • The curriculum library displays hierarchy, provenance, source revisions, and readiness. Source authoring stays outside the UI; ingestion is a documented future extension.
  • Playground stays internal. Provider credentials remain server-side, and the recorded submission is for the human author to make.

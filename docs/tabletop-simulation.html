03 · authoring + schema

Same lesson content, two starting paths

Teacher-authored · no AI draft

  1. Select offering, target, and duration.
  2. Fill objective, materials, timed actions, and check for understanding.
  3. Select approved chunks in a source picker.
  4. Server validates and saves teacher_authored v1.
  5. Submit; lead reviews that immutable version.

AI-assisted · draft, guidance, edits

  1. Retrieve eligible chunks; freeze exact run inputs.
  2. Generate JSON; validate and save ai_draft v1.
  3. Review suggests changes; it cannot mutate or approve.
  4. Teacher applies/dismisses; save creates teacher_edit v2.
  5. Rerun QA, submit v2, and review v2.

05 · QA indicators

Three decisions stay separate

Every report names exact planVersionId.
CODE · HARD GATE

Mechanical validation

passed / failed
Schema, scope, references, duration, rules, roles, transitions. Failure blocks regardless of model score.

JEV / LLM · ADVISORY

Semantic QA

not_run / recorded_fixture / evaluated / unavailable
Alignment, source support, assessment fit, clarity, feasibility, safety, accessibility.

CURRICULUM LEAD

Human review

pending / returned / approved
Lead reviews the exact submitted version.

Deliberate semantic failure

Draft says gas particles expand; cited note says spacing changes. Chunk membership passes; QA flags contradiction. Plan stays Draft until teacher edits.

Jev: typed judge signal

Choice: supported / contradicted / insufficient evidence for one claim. Score: one objective-to-check rubric. Noul: yes-probability from 0 to 1 for one misconception question; no separate confidence field. Route low Choice/Score confidence, disagreement, or Noul values near a set threshold to a human.

06 · deterministic loop

Reject invalid states before publication

  • Target belongs to offering and release.
  • Required official grounding exists; resources are eligible.
  • AI chunks belong to frozen run.
  • Teacher chunks were selected, approved, and in scope.
  • Positive activity times sum to content duration.
  • First AI draft matches requested duration.
  • Objective references resolve in this version.
  • Mandatory structured guidance is satisfied.
  • QA and lead decision name current version.
  • Hard failure cannot be overridden by a model score.

07 · prompt cards

Model returns data; app owns workflow

Generate · JSON content only

Use only supplied target, chunks, and structured rules. Target and duration are fixed. Cite allowed chunk IDs beside the objectives, activities, and checks they support. Invent no IDs or curriculum claims. If sources cannot ground a safe useful plan, return a typed grounding-gap error. Do not include plan or workflow metadata.

Review · findings and suggestions, no mutation

Review one immutable version against target, cited passages, and rules. Return code, dimension, severity, section path, evidence IDs, and optional suggestion. Flag unsupported claims, contradictions, target drift, assessment fit, clarity, pacing, safety, and accessibility. Separate evidence from advice. Do not rewrite, add sources, change state, submit, or approve. Say when evidence is insufficient.

02 Three separate version histories

1. Curriculum design

The official curriculum release and the system’s revision of that release’s structured tree.

July 2024 · r1 → r2 correction to imported structure
  • Different official release? New edition.
  • Corrected import of same release? New revision.
  • Targets and strands are scoped to this design version.

2. Source document

A particular revision of the source text used to ground targets or teaching.

KICD Grade 8 source · revision 1 · hash recorded
  • Owns text, URL, edition label, status, and content hash.
  • Target links select the revision and its role.

3. Lesson plan

Each teacher save creates a content snapshot tied to its selected target.

Plan version 3 → reviewed and validated as version 3
  • Later edits create version 4.
  • Old review/QA still names version 3.
What “freeze” means today

The version ID scopes its strand tree and target rows; published status marks it active. The database does not yet block edits to published rows or store a hash of the assembled tree, so this is a versioned grouping—not a hard immutable snapshot.
